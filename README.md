# 5x5 바둑 - 책과 함께 두기

5x5 바둑판에서 흑과 백을 직접 두어 보면서, 각 수가 **증명된 최선의 수**인지 책에서 확인하는 웹 페이지입니다.
컴퓨터는 두지 않습니다(탐색 없음). 책에 있는 국면만 판정합니다.

## 화면

| 표식 | 뜻 |
|---|---|
| 온전한 돌 / 미리보기에서 점 없는 빈 점 | 증명된 최선의 수 |
| 빨간 점 | 증명되지 않은 수 |
| 주황 점 | 증명되지 않은 수이지만, 두고 난 국면에서는 판정되는 수가 있음 |
| 녹색 점 | 값을 잃는 수 (증명됨). 어떻게 두어도 판 전체를 잃는 국면에서는 최선의 수도 녹색 |

- 판을 눌러 둡니다. 무르기는 버튼, 왼쪽 화살표(←), 백스페이스.
- "미리보기"를 켜면 빈 점마다 거기에 두었을 때의 판정이 색 점으로 보입니다.
- 주소 뒤에 `?moves=b3,c3,c4` 처럼 수순을 붙이면 그 국면에서 시작합니다.

## 규칙

중국식 계가(돌 + 집), 덤 없음, 자살수 금지, 같은 판 모양 반복 금지(국면 슈퍼코), 2연속 패스로 종국.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `go5core.js` | 규칙, 책 조회, 수 판정 |
| `go5_book.txt` | 논문에 실린 수순을 옮긴 책 (출처는 파일 머리말) |
| `go5_results.txt` | solver가 직접 증명한 국면들 (값과 최선의 수) |

책을 갱신하려면 두 txt 파일만 새것으로 바꾸면 됩니다.

## 출처

초반 수순과 첫 수별 값은 아래 논문과 저자의 웹 페이지에서 옮겼습니다. 논문의 값은 단순 패 규칙으로 구한 것이고,
`go5_results.txt`의 증명은 국면 슈퍼코 규칙으로 한 것이라 깊은 곳에서 차이가 있을 수 있습니다. 같은 국면이 양쪽에 있으면 증명 결과가 우선합니다.

- E. van der Werf, H. J. van den Herik, J. Uiterwijk, "Solving Go on Small Boards", ICGA Journal 26(2), 2003.
- O. Randall, M. Müller, T.-H. Wei, R. Hayward, "Expected Work Search", IJCAI 2024.
