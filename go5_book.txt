# go5_book.txt - 논문에 실린 5x5 해답을 옮긴 책. solver5 가 시작할 때 읽는다 (파일 모드, -play).
#
# 줄 형식:   값  출처 : 수순
#   값    = 최선으로 두었을 때의 결과, 흑 기준 집 차이 (+3 = 흑 3집 승, -1 = 백 1집 승)
#   수순  = 빈 판에서 시작하는 수순. 좌표는 열 글자 + 행 번호, 패스는 pass.
#   '|'   = 여기부터의 국면만 책에 넣는다. '|' 가 없으면 빈 판부터 넣는다.
#           (첫 수가 최선이 아닌 수순은 빈 판의 값이 다르므로 첫 수 뒤에 '|' 를 둔다)
#   책에 들어가는 것: 수순의 각 국면에 "값 + 다음 수". 마지막 국면에는 값만 들어간다.
#   회전/뒤집기로 같은 국면은 자동으로 같은 국면으로 본다. 같은 국면이 두 번 나오면 먼저 나온 줄이 우선.
#
# 출처
#   MIGOS2003 : van der Werf, van den Herik, Uiterwijk, "Solving Go on Small Boards",
#               ICGA Journal 26(2), 2003.  Figure 12 (최선 수순), Figure 13 (첫 수별 값)
#   MIGOS2002web : 같은 저자의 웹 페이지 "5x5 Go is solved" (2002.12) 의 기보 그림
#   EWS2024   : Randall, Mueller, Wei, Hayward, "Expected Work Search", IJCAI 2024.
#               국면 슈퍼코 규칙으로 c3 = 흑 25집 승을 확인 (수순은 실려 있지 않음)
#   solver    : 이 solver 가 직접 증명한 수순 (국면 슈퍼코). 논문 수순이 solver 증명과 달랐던 곳을 바꿔 넣은 것
#
# 주의: MIGOS 의 값은 단순 패(일본식) 규칙으로 구한 것이고 이 solver 는 국면 슈퍼코를 쓴다.
#       c3 의 +25 는 EWS2024 가 국면 슈퍼코로도 확인했다. c2(+3), b2(-1) 와 변 첫 수(-25)는 논문 값 그대로이다.
#       b2 수순의 11수째 이후와 그 변화는 solver 증명과 달라 solver 수순으로 바꿨다 (출처 solver).
#       solver 가 직접 증명한 국면(go5_results.txt)이 있으면 언제나 그쪽이 우선한다.

# 첫 수 c3: 흑 25집 승 (Figure 12a 의 15수 + 웹 기보의 나머지)
+25 MIGOS2003 : c3 b2 c2 b4 b3 c4 d4 d5 d3 a3 c1 e2 a2 a1 b1 a2 a4 a2 b5 d2 c5 e3 c4

# 첫 수 c2 (= b3, c4, d3): 흑 3집 승 (Figure 12b)
+3 MIGOS2003 : c2 | c3 d3 d2 d1 b2 e2 c4 b1 a2 d4 c5 a4 b4 c1 a3 d5 a5 a1

# 첫 수 b2 (= b4, d2, d4): 백 1집 승 (Figure 12c 의 10수째까지)
-1 MIGOS2003 : b2 | c3 c2 d3 b3 b4 a4 b5 d2 e2
# 11수째부터는 solver 수순. 논문의 흑 11수 e4 는 solver 로는 백 2집 승이 되어 최선이 아니고, a3 이 백 1집 승을 지킨다.
-1 solver : b2 c3 c2 d3 b3 b4 a4 b5 d2 e2 | a3 d5 a1 c4 e5 e4 d1 a5 c1 e3 e1 pass

# 변의 첫 수: 모두 백 25집 승 (Figure 13). 응수는 실려 있지 않아 값만 넣는다.
-25 MIGOS2003 : a1 |
-25 MIGOS2003 : a2 |
-25 MIGOS2003 : a3 |

# ---------------------------------------------------------------------------
# 변화 (실수한 수 뒤의 국면). 실수까지의 수순은 '|' 앞에 두어 책에 넣지 않고,
# 실수 직후의 국면부터 "값 + 최선의 응수"를 넣는다.
# ---------------------------------------------------------------------------

# c2 수순에서 백이 6수째를 e2 로 뻗은 실수 -> 빅이 되어 흑 5집 승
#   (논문 6.2절: "Extending with White 6 at 7 is a mistake and leads to a seki won with 5 points by Black", 수순은 웹 기보 "Mistake at 6")
+5 MIGOS2002web : c2 c3 d3 d2 d1 e2 | b2 d4 c4 b3 b4 a3 a2 e3 a4 d3 d5 c5 b5 c1 b1 e4

# b2 수순에서 흑이 11수째를 e4 로 둔 수 (논문 Figure 12c 의 수) -> solver 로는 백 2집 승
#   논문은 그 뒤 백 16수 a3 을 실수(무승부)라고 했으나 solver 로는 a3 이 백의 최선이다.
-2 solver : b2 c3 c2 d3 b3 b4 a4 b5 d2 e2 e4 | e3 d4 c4 d1 a3 d5 c5 a2 b1 e1 e5 d4 a5 pass c1 pass

# b2 수순에서 흑이 11수째를 d1 로 둔 실수 -> solver 로는 백 4집 승
#   (논문 6.2절은 판 전체를 잃는다고 했으나, 웹 기보 "Mistake at 11" 은 흑이 19수째에 a5 로 한 번 더 실수한 수순이다. e1 이면 4집으로 막는다)
-4 solver : b2 c3 c2 d3 b3 b4 a4 b5 d2 e2 d1 | a3 a2 b1 e3 e4 d5 c4 e1 e3 d4 a5 e5 c5 d5 a3 d4 pass
